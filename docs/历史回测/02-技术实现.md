## 💾 数据存储

### IndexedDB 结构

#### 历史数据表 (stocks_history)

```typescript
interface StockHistory {
  code: string; // 股票代码（主键）
  name: string; // 股票名称
  klineData: KLineData[]; // K线数据数组
  savedAt: number; // 保存时间戳
}

interface KLineData {
  date: string; // 日期（YYYYMMDD）
  open: number; // 开盘价
  high: number; // 最高价
  low: number; // 最低价
  close: number; // 收盘价
  volume: number; // 成交量
  amount: number; // 成交额
}
```

#### 回测结果表 (signal_backtests)

```typescript
interface SignalBacktest {
  code: string; // 股票代码（主键）
  name: string; // 股票名称
  signals: SignalResult[]; // 信号结果数组
  savedAt: number; // 保存时间戳
}

interface SignalResult {
  signalDate: string; // 信号日期
  entryPrice: number; // 入场价格
  returns: number[]; // 后续N日收益率数组
}
```

### 核心操作

```typescript
// src/utils/storage/opportunityIndexedDB.ts

// 获取所有股票历史数据
export async function getStocksHistory(codes: string[]): Promise<StockHistory[]> {
  return new Promise((resolve, reject) => {
    const request = indexedDB.open(DB_NAME, DB_VERSION);
    request.onsuccess = (event) => {
      const db = (event.target as IDBOpenDBRequest).result;
      const transaction = db.transaction(['stocks_history'], 'readonly');
      const store = transaction.objectStore('stocks_history');

      if (codes.length === 0) {
        // 获取所有数据
        const getAllRequest = store.getAll();
        getAllRequest.onsuccess = () => resolve(getAllRequest.result);
      } else {
        // 获取指定股票
        const results: StockHistory[] = [];
        let completed = 0;

        codes.forEach((code) => {
          const getRequest = store.get(code);
          getRequest.onsuccess = () => {
            if (getRequest.result) {
              results.push(getRequest.result);
            }
            completed++;
            if (completed === codes.length) {
              resolve(results);
            }
          };
        });
      }
    };
  });
}

// 保存回测结果
export async function batchSaveSignalBacktests(results: SignalBacktest[]): Promise<void> {
  return new Promise((resolve, reject) => {
    const request = indexedDB.open(DB_NAME, DB_VERSION);
    request.onsuccess = (event) => {
      const db = (event.target as IDBOpenDBRequest).result;
      const transaction = db.transaction(['signal_backtests'], 'readwrite');
      const store = transaction.objectStore('signal_backtests');

      results.forEach((result) => {
        store.put(result);
      });

      transaction.oncomplete = () => resolve();
      transaction.onerror = () => reject(transaction.error);
    };
  });
}
```

## ⚙️ 回测引擎

### 规则扫描架构

**文件**: `src/utils/analysis/buypointScenario.ts`

页面从 IndexedDB 读取 `stockHistory`，在主线程调用以下函数完成扫描：

- `scanHistoricalBuyPoints()` — 扫描历史好买点（至少命中 3 项规则）
- `scanLatestScenarioSignals()` — 扫描最新交易日高 lift 场景信号

### 场景分类

每条 K 线根据量价特征匹配预定义场景（如连板/强趋势、放量突破续涨等），规则只使用 `lines[0..i]`，不偷看未来。

### 收益验证

识别买点后，计算后续 1/2/3/5/10 个交易日的收益率，用于统计胜率与 lift。

离线脚本复用同一套规则：

- `scripts/scan-buypoint-signals.cjs`
- `scripts/classify-buypoint-scenarios.cjs`
- `scripts/classify-latest-day.cjs`
- `scripts/lib/buypoint-scenario-lib.cjs`

```typescript
// src/pages/BacktestPage/BacktestPage.tsx
const handleExportStock = async (code: string, dates: string[]) => {
  try {
    // 1. 获取股票历史数据
    const histories = await getStocksHistory([code]);
    if (histories.length === 0) {
      message.error('未找到股票数据');
      return;
    }

    const stockData = histories[0];

    // 2. 构建导出数据
    const exportData = {
      code: stockData.code,
      name: stockData.name,
      klineData: stockData.klineData,
      buyPoints: dates.map((date) => ({
        date,
        verified: true,
      })),
      exportedAt: new Date().toISOString(),
    };

    // 3. 转换为JSON
    const jsonContent = JSON.stringify(exportData, null, 2);

    // 4. 通过Electron保存到本地
    const result = await window.electronAPI.saveStockData({
      code: stockData.code,
      name: stockData.name,
      klineData: stockData.klineData,
      dates,
      exportContent: jsonContent,
      exportFilename: `backtest_${code}_${formatDate(new Date())}.json`,
    });

    if (result.success) {
      message.success(`导出成功: ${result.filePath}`);
    } else {
      message.error('导出失败');
    }
  } catch (error) {
    logger.error('导出股票数据失败:', error);
    message.error('导出失败');
  }
};
```

### 数据分组

```typescript
// 将信号按股票分组
function groupSignalsByStock(signals: any[]): any[] {
  const grouped: Map<string, any> = new Map();

  signals.forEach((signal) => {
    const { code, name, signalDate, entryPrice, returns } = signal;

    if (!grouped.has(code)) {
      grouped.set(code, {
        code,
        name,
        signals: [],
        totalSignals: 0,
        avgReturn: 0,
        winRate: 0,
      });
    }

    const group = grouped.get(code)!;
    group.signals.push({ signalDate, entryPrice, returns });
    group.totalSignals++;
  });

  // 计算统计信息
  grouped.forEach((group) => {
    const allReturns = group.signals.flatMap((s) => s.returns);
    group.avgReturn = allReturns.reduce((sum, r) => sum + r, 0) / allReturns.length;

    const winCount = allReturns.filter((r) => r > 0).length;
    group.winRate = (winCount / allReturns.length) * 100;
  });

  return Array.from(grouped.values());
}
```

## 🔧 扩展指南

### 添加新的买点场景

1. 在 `src/utils/analysis/buypointScenario.ts` 的 `SCENARIOS` 中注册新场景
2. 在 `classifyScenario()` 中添加匹配规则（只使用 `lines[0..i]`）
3. 同步更新 `scripts/lib/buypoint-scenario-lib.cjs`（离线脚本共用规则）
4. 如需纳入高 lift 筛选，更新 `HIGH_LIFT_SCENARIOS`

### 优化扫描性能

- 使用「排除 ST」等筛选减少扫描范围
- 大量股票时优先在页面内分批扫描，避免一次性加载过多数据

## 🐛 常见问题排查

### 问题 1: 回测速度很慢

**症状**：回测大量股票时耗时过长

**排查步骤**：

1. 检查 CPU 使用率
2. 检查 IndexedDB 中股票数量
3. 检查是否有内存泄漏

**解决方案**：

- 勾选「排除 ST」或使用筛选缩小范围
- 减少单次扫描的股票数量
- 使用更高效的浏览器（Chrome/Edge）

### 问题 2: IndexedDB 存储空间不足

**症状**：保存数据时失败

**排查步骤**：

1. 检查浏览器存储限制
2. 查看 IndexedDB 使用情况
3. 清理过期数据

**解决方案**：

- 定期清理旧的回测结果
- 压缩存储的数据
- 使用分页加载
