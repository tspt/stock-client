## 📊 功能概览

### 核心能力

```
历史回测系统
├── 数据管理
│   ├── IndexedDB 历史数据存储
│   └── 股票筛选配置
├── 回测引擎
│   ├── 规则买点场景扫描
│   └── 信号识别与收益验证
├── 结果展示
│   ├── 按股票分组展示
│   ├── 胜率统计
│   └── 收益分析
└── 数据导出
    ├── 单股票导出
    └── 批量导出
```

### 技术特性

- ✅ **本地回测** - 基于 IndexedDB 全量历史数据，无需联网
- ✅ **规则扫描** - 基于买点场景规则识别历史好买点与最新交易日信号
- ✅ **智能筛选** - 支持市场类型、名称类型、时间范围筛选
- ✅ **灵活导出** - 支持导出为 JSON 或 Excel 格式
