# 机会记录

存放机会分析「添加到记录」的每日快照。

- 路径：`docs/回测优化/机会记录`
- 命名：按分析日期，如 `2026-08-10.json`
- 同名文件会覆盖

## JSON 格式

```json
{
  "version": "1.0",
  "kind": "opportunity-record",
  "date": "2026-08-10",
  "createdAt": 1780000000000,
  "updatedAt": 1780000000000,
  "stocks": [
    {
      "code": "SH600151",
      "name": "航天机电",
      "concepts": [],
      "timestamp": 1780000000000
    }
  ]
}
```

## 读取方

- **分析记录**页：统计、趋势图
- **历史回测**页：买点追踪与最新买点 JSON 交叉比对
