一、趋势判断：先看大方向
均线多头排列是基础门槛
5周、10周、20周、60周均线由下向上依次排列，且开口不大，说明中期趋势健康。
20周均线被视为"牛熊分界线"或"生命线"，股价站稳且向上拐头，中期趋势才成立。
60周均线走平或上翘，是主升浪启动的标志。
直接排除股价长期在60周均线下方、均线向下发散的个股。
MACD辅助确认
周线MACD在零轴上方金叉为强势加仓信号；零轴下方金叉多为弱势反弹，需谨慎。
周线底背离（股价创新低但MACD未同步新低）是中级底部反转信号。
二、核心买入战法
1. 平台突破法
股价低位横盘8-12周，波动幅度≤20%，均线粘合。
某周放巨量（达近5周均量1.5倍以上），收中长阳（涨幅≥5%）并站稳平台高点，为启动信号。
平台整理时间越久、量能越稳定，突破后行情力度越强。
2. 回踩低吸法
上升趋势中，股价缩量回调至5周、10周或20周均线附近。
出现止跌K线（锤子线、十字星、阳包阴）且均线仍向上，为理想买点。
3. 连续堆量法
连续3周以上温和放量形成"堆量"，说明增量资金持续进场。
中途缩量回踩不破5周或10周均线，再次放量站回均线为买点。
4. 均线金叉法
7周线上穿14周线，随后14周线上穿60周线（或34周线），金叉段放量，为强势股信号。
5周线金叉10周线为短线走好信号。
5. 老鸭头形态
5周、10周均线金叉后股价上行，随后缩量回调，5周均线走平靠近但不跌破10周线。
再次放量，5周线重新昂头向上，MACD在水上拒绝死叉或小幅死叉后迅速再度金叉，为入场点。
6. 三连阳回踩法
周线连续3周收阳，回踩5周均线时成交量缩至前三周均量一半以下，企稳后入场。
三、多周期共振：周线选股，日线买股
周线站在5周均线上方（定方向）
日线站在20日均线上方（定主力控盘）
两个条件同时满足时分批介入，成功率大幅提升。
四、风险控制与卖出信号
止损原则
有效跌破20周均线或10周线拐头向下，果断止损。
卖出信号
股价累计涨幅超40%后，周线出现放量长上影线或MACD顶背离。
短期均线下穿长期均线形成"死叉"。
上涨时间达5周左右，无论盈亏考虑卖出锁定利润。
高位放量滞涨（天量成交但K线实体极小），主力出货信号。
